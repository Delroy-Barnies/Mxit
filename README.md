# Mxit Frontend
Welcome! This is the frontend for my Mxit-inspired messaging application. Built using React.js, the app delivers a clean and responsive user experience, 
leveraging modern state management and modular CSS for styling.

***ReactJs 18x***
***Vite 6x***
***Html5 and CSS3***
***ECMAScript 2024 (ES15)***

## Installation

Clone the repository:
git clone https://github.com/yourusername/mxit-server-api.git
cd mxit-server-api

Install dependencies:
npm install

Setup environment variables:
Create a .env file based on .env.example

Start the server:
npm run dev

## Tech Stack

- React.js (v18.x) – UI library for building component-based interfaces
- Vite (v6.x) – Lightning-fast development server and bundler
- HTML5 – Markup language
- CSS3 with CSS Modules – Styling with component-level isolation
- ECMAScript 2024 (ES15) – Modern JavaScript standard
